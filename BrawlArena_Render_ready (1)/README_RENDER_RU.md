# Brawl Arena Sakura Online — Render

Основано на исходном архиве `BrawlArena_online_backend_v0_1.zip`. Игра находится в `www/index.html`, сервер — в `server/server.js`. Путь к `www` и каталогу данных адаптирован под эту структуру.

Настройки Render:
- Runtime: Node
- Build Command: `npm install`
- Start Command: `node server/server.js`

Проверка после деплоя: открой `/api/ping`. Успешный ответ должен содержать `"ok":true`.

Важно: сервер сейчас хранит данные в JSON-файле `server-data/db.json`. На бесплатном Render локальная файловая система обычно не является постоянным хранилищем при перезапусках/новых деплоях. Перед использованием с реальными аккаунтами подключи постоянное хранилище/базу данных. Онлайн-бой необходимо отдельно проверить двумя браузерами/устройствами; сам успешный запуск API не доказывает, что весь матч работает корректно.
