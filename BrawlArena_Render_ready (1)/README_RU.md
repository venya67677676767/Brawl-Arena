# Brawl Arena: Sakura Update — браузерная игра и начальный сервер

Игра сохраняется как обычная веб-страница: приложение для Windows или Android устанавливать не нужно. Основной файл игры скопирован в `www/index.html` из последней версии `Brawl Arena_sakura_update (6).html`.

## Локальный запуск сайта
1. Установи Node.js 20 или новее.
2. Открой терминал в папке проекта.
3. Запусти `npm run server`.
4. Открой `http://localhost:3000` в браузере.

## Что сейчас есть в серверной основе
- API проверки доступности сервера (`/api/ping`).
- Создание аккаунта по нику и паролю; пароли хешируются через `scrypt`, пароль в открытом виде не хранится.
- Серверные сессии-токены.
- Загрузка и сохранение игрового профиля на стороне сервера.
- SSE-соединение для событий, базовая система друзей/лобби и передача сообщений между участниками лобби.
- Запись тестовых данных в `server-data/db.json` для локальной разработки.

## Чего пока НЕ следует считать готовым
- Сервер не размещён публично, поэтому игроки из интернета пока не могут подключиться к одному общему серверу.
- Хранилище JSON — только для разработки. Для публичного сервера нужна облачная база данных и резервное копирование.
- Подбор случайных игроков, присоединение по коду комнаты через интерфейс, полноценная проверка игровых действий сервером, надёжная обработка переподключения и заполнение матча ботами ещё не завершены.
- Синхронизацию боя нужно проверить между двумя отдельными браузерами/устройствами после запуска сервера; не считать онлайн готовым до такого теста.

## Следующие этапы
1. Подключить настоящую облачную БД и постоянное хранилище.
2. Добавить интерфейс создания комнаты и входа по коду.
3. Реализовать случайный подбор игроков и заполнение свободных мест ботами.
4. Перевести расчёт боя на авторитетную серверную логику и провести тесты с двумя устройствами.
5. Разместить сервер по публичному HTTPS-адресу. Только после этого игра станет доступна по ссылке из любой точки.

Не помещай приватные ключи или секреты в HTML. Этот проект пока является начальной реализацией, а не объявлением о готовом публичном онлайне.
