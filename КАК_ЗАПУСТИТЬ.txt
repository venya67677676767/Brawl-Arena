КАК ЗАПУСТИТЬ ИГРУ КАК ПРИЛОЖЕНИЕ С СЕРВЕРОМ — за 5 минут
================================================================

ВАРИАНТ А — просто поиграть (без друзей по сети), 1 минута:
1. Открой файл index.html двойным кликом.
2. Нажми «Регистрация», придумай ник (3–16 символов) и пароль (от 4 символов).
3. Играй. Прогресс сохраняется в браузере.
4. Режим БОСС-ФАЙТ ищи в «ИГРАТЬ → 🦊 БОСС-ФАЙТ · КИЦУНЭ».

ВАРИАНТ Б — общий сервер для друзей, 5 минут:
1. Установи Node.js с https://nodejs.org (кнопка LTS, далее-далее-далее).
2. Распакуй папку brawl-arena-online.
3. Открой терминал/командную строку ВНУТРИ папки brawl-arena-online и выполни:
     node server/server.js
   Должно появиться: «🦊 BRAWL ARENA сервер запущен: http://localhost:3000»
4. Открой в браузере http://localhost:3000 — это та же игра, но уже С СЕРВЕРОМ.
   Зарегистрируйся. Ник и пароль теперь хранятся на сервере, прогресс тоже.
5. Друг рядом (тот же Wi-Fi):
   - узнай свой IP: Windows → ipconfig, Mac/Linux → ifconfig (например 192.168.1.5)
   - друг открывает http://192.168.1.5:3000 и регистрируется.
   - вы добавляете друг друга в друзья по нику (оба должны добавить ✅).
   - один создаёт лобби (кнопка «В лобби»), второй заходит, хозяин жмёт ИГРАТЬ.
6. Друг далеко (интернет): залей папку на https://render.com (Web Service, команда node server/server.js)
   и дай друзьям ссылку. Дальше всё так же.

КАК СКАЧАТЬ КАК ПРИЛОЖЕНИЕ (без нового файла каждый раз):
- Открой игру ЧЕРЕЗ СЕРВЕР (http://localhost:3000, не двойным кликом).
- В Chrome нажми ⋮ → «Сохранить и поделиться → Установить» или кнопку «📲 Скачать как приложение» в лобби.
- Игра появится как отдельное окно/иконка. Обновления приходят САМИ: меняешь файлы + version.json —
  у игроков всё обновляется при следующем запуске, скачивать заново НЕ нужно.

ЧТО ЕСЛИ ЧТО-ТО НЕ ТАК:
- «Нет связи с сервером» — значит index.html открыт без сервера. Это нормально: игра работает офлайн с ботами.
  Для общего онлайна запусти node server/server.js (см. выше).
- Порт занят — запусти node server/server.js с другим портом:
     Windows:  set PORT=4000 && node server/server.js
     Mac/Linux: PORT=4000 node server/server.js
- Забыл пароль — пока сброса нет: создай новый ник или удали запись в server/db.json.
